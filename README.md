# DDT Recorder Pilot

Standalone functional pilot implementation of the Diamond Data Chain DDT Recorder.

## Scope

- DDT Recorder ingestion and normalization
- Canonical record production
- Evidence manifest and commitments
- Conformance receipts and Ed25519 proofs
- Atomic DDT registration
- Replay and source-event conflict protection
- PostgreSQL / Neon durable storage
- Retrieve and verification API
- Offline verification package implementation
- Recorder Pilot UI

## Related repositories

- `Diamond-Data-Chain/ddc-specifications` — authoritative DDT specifications
- `Diamond-Data-Chain/ddc-verification-fixtures` — verification fixtures
- `Diamond-Data-Chain/ddc-web` — public DDC website integration

This repository contains the standalone Recorder Pilot implementation.
